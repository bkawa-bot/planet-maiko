Planet Maiko

A personal engineering companion that unifies your notifications, triages with AI, and orchestrates self-specializing coding agents.

Features

✉

Unified Inbox

GitHub PRs, Linear issues, Calendar events, and agent updates in one stream. Smart filtering by source, priority, and type.

⚙

CPU-Style Brain

5-phase processing pipeline: agent monitoring, conflict detection, incident correlation, rule-based triage, and learning. Rules handle 80% for free.

★

Self-Specializing Agents

Agents are context strategies, not personas. Pups explore with random learning sets, seniors exploit proven ones. Tournament training with LLM-as-judge.

✓

Self-Learning System

Signals from PR comments graduate into active rules. Tournament system validates against real merged PRs. Context optimization tracks what actually works.

♥

Focus Mode

Gate notifications by your state: available, soft focus, deep focus, away. Held items escalate over time. Maiko respects your attention.

⚛

Configurable Skills

Morning briefs, brainstorms, investigations, repo analysis. Schedule skills to run automatically. Results become notifications from Maiko.

☼

Live Scene Engine

Dynamic pixel-art backgrounds based on real weather, time of day, season, and holidays. Live weather via Open-Meteo. Maiko changes outfits.

⚓

Pluggable Everything

Pollers, runtimes, rules, and skills are all plugin-based via Python entry points. Default runtime is Claude Code. Bring your own brain.

Architecture

Modeled on a CPU — each brain cycle processes through a pipeline

Brain Cycle (every 5 min)

Agent Monitor Conflict Detection Correlator Pupdate Processor Learning

Agent Context Loop

Task arrives → compile learning brief for agent's specialization → agent works with personalized context → outcome recorded → specialization scores update → next task gets better-targeted learnings.

Self-Learning Pipeline

PR comments become signals → signals aggregate into learnings → learnings graduate at confidence thresholds → tournament system validates against real PRs → active rules compiled into agent briefs.

Get Started

1

Clone & install

git clone https://github.com/bkawa-bot/planet-maiko.git
cd planet-maiko
pip install -e .
2

Install frontend

cd frontend
npm install
cd ..
3

Run (two terminals)

# Terminal 1
maiko serve

# Terminal 2
cd frontend && npm run dev
4

Open & configure

Open http://localhost:5173
Go to Settings to connect GitHub, Linear, Calendar, and weather.
