# Screenshots

The main README references three images in this directory. Drop
actual PNGs here and they'll render.

| File | What it should show |
|------|---------------------|
| `home.png` | Home page — Pack Requests widget + overview pane + sprite mood + scene/weather. The hero shot. Ideally captured on a clear-day theme with at least one pending Pack Request visible. |
| `campfire.png` | Pack Insights ritual (Agents tab → Pack Insights) with agents sharing feedback and insights, awaiting approval. Shows the self-learning loop visually. |
| `review.png` | Review Diff page (`/tasks/<id>/review`) with the verdict banner at top and at least one inline comment. Shows the in-app review flow — no terminal needed. |

Recommended format: PNG, ~1600px wide, with a light-mode or sunset theme for warmth. If you rotate themes, take the hero shot in one consistent look so the three images feel like a set.
